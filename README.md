# Azbuka — бот контроля отчётов тренеров

Бот помогает следить за ежедневными отчётами тренеров в родительских чатах MAX, напоминать о несданных, учитывать набранные номера и считать начисления за период.

---

## Для кого

- **Администраторы** — видят статусы, штрафы, зарплату, привязывают чаты и тренеров
- **Тренеры** — сдают отчёты в родительских чатах; получают напоминания в общем чате тренеров

Управление идёт через **MAX**. Telegram можно использовать как резервный канал, если он включён.

---

## Как сдаётся отчёт

В родительском чате локации тренер отправляет сообщение с фразой **«Сегодня тренировка»**.

В том же сообщении можно указать набранные номера:

```
Сегодня тренировка

С пробного:
+7 999 111-22-33

С общения:
+7 900 555-44-33
```

- Номера учитываются **только** под заголовками «С пробного» и «С общения»
- Если в сообщении есть видео — это засчитывается как видео-отчёт за неделю

Отчёт принимается, если:

- чат привязан к локации
- сегодня у этого тренера рабочий день на этой локации
- день не праздничный и не отменён администратором

---

## Напоминания и штрафы

| Когда | Что происходит |
|---|---|
| **22:00** | В общий чат тренеров — кто не сдал отчёт и по каким локациям |
| **23:59** | За несданный отчёт начисляется штраф |
| **Суббота 13:00** | Проверка видео за неделю; если видео не было — штраф |
| **15-е и конец месяца** | Сводка штрафов для расчёта зарплаты |

Праздники и отменённые администратором дни в штрафы не входят.

---

## Зарплата по номерам

За каждый сохранённый номер:

- **С пробного** — +50 ₽
- **С общения** — +100 ₽

Периоды расчёта:

- с **1 по 15** число
- с **16** по конец месяца

Команда `/salary` показывает сумму по тренерам и список учтённых номеров за текущий период.

---

## Команды администратора

| Команда | Назначение |
|---|---|
| `/status` | Кто сдал / не сдал отчёт сегодня |
| `/week` | Статистика за текущую неделю |
| `/month` | Статистика за текущий месяц |
| `/salary` | Начисления за текущий полумесячный период |
| `/stats` | Сводка по отчётам и штрафам за месяц |
| `/summary` | Штрафы за выбранный период |
| `/remove_penalty` | Список активных штрафов |
| `/rm_<id>` | Снять штраф |
| `/pending_chats` | Чаты MAX, куда добавлен бот, но ещё не привязанные к локации |
| `/bind_chat` | Привязать чат к локации |
| `/bind_trainer` | Назначить тренера на локацию и дни недели |
| `/assignments` | Список назначений |
| `/unassign` | Отключить назначение |
| `/trainers` | Тренеры и их идентификаторы |
| `/set_trainer_max` | Указать username тренера в MAX |
| `/day_off` | Отменить рабочий день (тренер / локации) |

В MAX удобно пользоваться и текстовым меню после `/start`.

---

## Типичный день

1. Утром бот уже знает, какие локации должны отчитаться (по расписанию тренеров)
2. Тренеры пишут отчёты в родительских чатах
3. В **22:00** в чат тренеров уходит напоминание по несданным
4. В **23:59** за пропуски начисляются штрафы
5. Админ в любой момент смотрит `/status`, `/salary`, снимает ошибочные штрафы или отменяет день

---

## Важно

- Бот реагирует на отчёты только в **привязанных** чатах
- Отчёт должен прийти от **назначенного** на этот день тренера
- Без открытия диалога с ботом администратор не получит ответы в личку MAX
